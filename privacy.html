개인정보 처리방침

시행일: 2026년 11월 4일

보따리는 한국 방문을 준비하는 데 필요한 여행 날짜, 장소, 할 일과 노트를 정리하는 앱입니다. 앱의 기본 기록은 기기에 저장하며 서버에 올려 보관하거나 동기화하지 않습니다. 사용자가 AI로 읽기를 요청할 때에는 아래에 설명한 자료가 처리를 위해 전송됩니다.

계정과 익명 세션

보따리에는 계정 생성, 로그인, 이메일 입력 기능이 없습니다. 서버 기능을 사용할 때 앱이 Supabase 익명 세션을 자동으로 만들고, Supabase 익명 사용자 ID를 사용합니다.

익명 사용자 기록(익명 사용자 ID)을 사용자가 직접 지울 수 있는 기능은 현재 제공하지 않습니다. 이 ID에 연결된 날짜별 요청 횟수 기록은 아래 “서버 사용량 기록”에 적은 대로 90일이 지나면 자동으로 삭제됩니다.

기기에 저장되는 기록

다음 정보는 기기 안에 저장되며, 서버에 저장하거나 서버로 동기화하지 않습니다.

  • 여행 날짜와 동행 정보
  • 장소, 할 일, 노트
  • AI로 읽어 온 결과
  • 읽어 온 스크린샷과 링크의 이미지를 줄인 사본(가로 1080px 이하)
  • 읽기 전의 원본 스크린샷과, 다른 앱의 공유 화면으로 받은 이미지·링크·글(읽거나 저장할 때까지 앱의 보관 영역에 둡니다)

스크린샷 원본은 읽은 결과를 저장하거나 “다시 올리기”를 고르면 기기에서 지웁니다. 줄인 사본은 카드와 상세 화면에 보여 주려고 기기에 남깁니다.

앱을 삭제하거나 설정에서 “이 기기의 모든 기록 지우기”를 누르면 위 기록과 이미지가 기기에서 삭제됩니다. 언어와 기본 지도 앱 설정은 남습니다. 사용자가 AI로 읽기를 요청할 때 처리되는 자료와 서버 사용량 기록은 아래 항목을 참고해 주세요.

AI로 읽기

사용자가 앱에서 “읽어 오기”를 누른 경우에만 선택한 이미지나 텍스트(링크에서 가져온 미리보기 글 포함), 그리고 공유할 때 적은 메모가 Supabase 서버를 거쳐 Anthropic API로 전송되어 Anthropic이 처리합니다. 보따리 서버는 이미지와 글을 저장하지 않습니다. Anthropic의 개인정보 처리는 Anthropic 개인정보 처리방침을 따릅니다.

링크 읽기

사용자가 링크를 붙여 넣으면 앱이 사용자의 기기에서 그 링크의 웹사이트에 직접 접속해 미리보기 정보(제목과 설명 글, 대표 이미지)를 가져옵니다. 이때 해당 웹사이트는 사용자의 기기에서 온 요청을 받습니다. 앱은 로그인하지 않으며, 로그인이 필요한 내용은 읽지 않습니다.

가져온 제목과 설명 글만 AI 읽기에 사용하며, 링크 주소와 페이지 전체, 대표 이미지는 보따리 서버로 보내지 않습니다. 대표 이미지는 기기에 저장합니다.

장소 검색

사용자가 장소의 지점을 찾으면 장소 이름과 동네를 담은 검색어가 Supabase 서버를 거쳐 Kakao 장소 검색 API로 전달되어 Kakao가 처리합니다. Kakao의 개인정보 처리는 Kakao 개인정보 처리방침을 따릅니다. 앱은 기기 위치를 수집하거나 전송하지 않습니다.

서버 사용량 기록

서버 기능의 사용량 제한과 운영을 위해 Supabase 익명 사용자 ID, 날짜별 기능 요청 수, 이미지 수, AI 입력·출력 토큰 수를 기록합니다. 사용자별 사용량 기록은 90일이 지나면 자동으로 삭제됩니다.

이와 별도로 날짜별 기능 종류와 서비스 전체 요청 수 합계를 저장합니다. 이 집계에는 사용자 ID, 이미지 수, AI 토큰 수가 포함되지 않습니다. 현재 앱의 자동 삭제 작업은 사용자별 기록에 적용되며, 서비스 전체 집계에는 자동 삭제 기간이 설정되어 있지 않습니다.

English summary: Bottari stores trip dates, companions, places, tasks, notes, AI reading results, and reduced copies of the screenshots and link images you read on the device. Unread original screenshots stay on the device until you read or save them. When you request AI reading, the selected image or text (including preview text from a link) and any note you wrote when sharing are sent through Supabase to Anthropic, which processes them; Bottari’s server does not store them. See Anthropic’s privacy policy. When you paste a link, the app itself connects from your device to that website and reads its preview title, description, and image; that website receives the request from your device. The app does not log in, and only the preview title and description are used for AI reading. The link address, the full page, and the image are not sent to Bottari’s server. Place search sends the place name and area through Supabase to Kakao, which processes them; see Kakao’s privacy policy. The app does not collect or send device location. There is no feature to delete the anonymous user record. Per-user daily request-count records are automatically deleted after 90 days. Service-wide daily request totals are stored without a user ID and do not have an automatic deletion period configured. Contact bottari.support@gmail.com.
